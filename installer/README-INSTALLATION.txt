CPCREDO — installation
Caisse Populaire Épargne et de Crédit pour le Développement de l’Ouest
Pétion-Ville, Haïti

SUR LE SERVEUR (un seul ordinateur)
1. Branchez la clé USB.
2. Ouvrez le dossier CPCREDO-USB.
3. Clic droit sur Installer-CPCREDO.exe
   → Exécuter en tant qu’administrateur.
4. Suivez les écrans. Cliquez sur Suivant.
5. À la fin, cliquez sur Démarrer.

Si Windows demande une autorisation, cliquez sur Oui.

Ne fermez pas la fenêtre pendant l’installation.
Une connexion internet n’est pas nécessaire si le dossier OfflinePackages est complet.

Le dossier du logiciel est : C:\CPCREDO
Adresse : https://IP-DE-CET-ORDINATEUR:5443
La première visite du navigateur peut afficher un avertissement (certificat du bureau). Choisissez Continuer vers le site.

SUR LES AUTRES PC (caissiers)
Double-cliquez INSTALLER-CLIENT.bat
Entrez le mot de passe d’installation, puis l’adresse IP du serveur.

Sauvegarde automatique : tous les jours à 18:30, dossier C:\CPCREDO\backups.
Journal d’installation : C:\CPCREDO\logs\install.log
